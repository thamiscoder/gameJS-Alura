Jogo do número secreto desenvolvido como estudo de JavaScript na Alura.  
O objetivo é adivinhar um número sorteado entre 1 e 10, recebendo dicas até acertar.

## Sobre o projeto

O `gameJS-Alura` é um jogo simples de adivinhação construído com HTML5, CSS3 e JavaScript.  
A aplicação sorteia um número secreto, recebe o palpite do usuário e informa se o número correto é maior ou menor.

O projeto também utiliza manipulação do DOM, controle de tentativas, botão para reiniciar a partida e leitura de mensagens por voz com ResponsiveVoice.

## Funcionalidades

- Sorteio de número aleatório entre 1 e 10;
- Entrada de palpite pelo usuário;
- Dicas indicando se o número secreto é maior ou menor;
- Contador de tentativas;
- Mensagem de vitória ao acertar;
- Botão para iniciar um novo jogo;
- Controle para evitar repetição de números até completar a sequência;
- Exibição de textos na tela via JavaScript;
- Leitura das mensagens com voz em português.

## Tecnologias utilizadas

- HTML5;
- CSS3;
- JavaScript;
- ResponsiveVoice.

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/thamiscoder/gameJS-Alura.git
```

2. Acesse a pasta do projeto:

```bash
cd gameJS-Alura
```

3. Abra o arquivo `index.html` no navegador.

Depois disso, basta digitar um número entre 1 e 10 e tentar descobrir o número secreto.

## Observação

Este projeto tem finalidade educacional e foi criado para praticar funções, condicionais, manipulação do DOM, geração de números aleatórios e controle de estado simples em JavaScript.
